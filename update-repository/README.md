# Kodepoia public update repository

This directory is the public R19.2 TUF metadata publication root.

The canonical metadata endpoint is:

```text
https://raw.githubusercontent.com/LaurentCOLL1/Kodepoia/main/update-repository/metadata/
```

Installer payloads are hosted as immutable GitHub Release assets. TUF metadata remains the
authorization source.

No private key material may be stored anywhere in this directory.
