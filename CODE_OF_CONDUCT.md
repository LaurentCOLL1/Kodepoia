# Code of Conduct

Kodepoia development should remain professional, technically rigorous and respectful.

Contributors must:
- discuss technical disagreements on their merits;
- provide reproducible evidence for defects and performance claims;
- avoid harassment, personal attacks and discriminatory conduct;
- respect privacy, credentials, licences and confidential project data;
- clearly distinguish verified facts from assumptions;
- disclose conflicts or provenance issues when relevant.

Security concerns and private data must be handled through appropriate private channels rather than public discussion.
